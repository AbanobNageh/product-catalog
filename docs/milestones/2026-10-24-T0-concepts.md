## Decisions (link ADRs)
No ADRs; these are playground choices:
- **Folder:** `terraform/docker-basics/` for T0–T1, not a per-module folder; T2 starts `terraform/local/`.
- **Port:** `127.0.0.1:6380`, so Compose's Redis on 6379 can run alongside, bound to localhost only.
- **Image:** the same tag as Compose (`redis:8-alpine`), plus a `docker_registry_image` data source, so T0 has a data-source example and the image re-pulls when the tag moves.
- **`keep_locally = true`:** `destroy` leaves the image, which Compose shares.
- **Terraform 1.16.6 from winget** rather than the 1.17.0 zip: winget handles the PATH and upgrades, and `~> 1.16` accepts 1.17 later.
