## Review findings and corrections
1. **Is `AGENTS.md` needed alongside `CLAUDE.md`?** The user questioned it. It was kept for cross-tool portability, at no context cost thanks to the `@AGENTS.md` import. This was a clarification; nothing changed.
2. **"About me" isn't standard AGENTS.md content.** The user caught that a personal profile section doesn't belong in a shared repo file. It was restructured into "The learner" (only what shapes the tutoring), "Setup" and "Commands". The general Windows/PowerShell preference moved to the user-level `~/.claude/CLAUDE.md`.
3. **The AI put run and test commands in a Claude-only rules file.** This came out of finding 2: other tools could never have seen them. They now belong in `AGENTS.md`'s Commands section, and `services.md` tells the AI to keep that section updated.
4. **ADR-0001 didn't record the real reason for its choice.** The user pointed out that option 2 was chosen to learn one thing at a time, with option 3 (Kafka) planned for later. The ADR now says this. It also adds design constraints that keep the later switch cheap (one `SearchIndexer` interface, indexing logic separate from HTTP handlers, idempotent indexing), and that constraint was added to the spec.
5. **Found while committing:** the global `core.autocrlf=true` would give CRLF line endings in the working copy. `.gitattributes` was added to keep LF.
